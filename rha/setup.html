Setup

This ROM hack implementation requires Bizhawk Client to run which means the setup is identical to any other Bizhawk Client game.

Required Software
  • Archipelago 0.6.7 or newer
  • Software capable of loading and playing GBA ROM files. Anything not listed here is not guaranteed to work.
    • Bizhawk
  • A Rhythm Tengoku 1.0 JP ROM from the original cartridge.
      1.0 JP MD5: f81f60fdb2fd774c72a170a1805db52e

How to play
  1. Place the .apworld in your Archipelago/custom_worlds folder, or double-click the .apworld to do so automatically.
  2. Use ArchipelagoLauncher.exe to open the Launcher, and click on Generate Template Options to create template yamls for your custom .apworlds.
  3. Place the desired player yamls in the Players folder, and customize them as you see fit.
  4. Use ArchipelagoGenerate.exe to generate the game.
  5. Upload the generated game (in the output folder) on the website at https://archipelago.gg/uploads and create a new room.
  6. Download the patch file from the session page
  7. Open the .aprhythmadvance file with ArchipelagoLauncher.exe, it should create a ROM file and open Bizhawk Client.

Bizhawk
  1. Open the patch
  2. Bizhawk Client should automatically setup everything for you.
  3. Enjoy!
