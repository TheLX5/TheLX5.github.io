1.0.3

  • Removed Photo Album and Credits sequence when beating K. Rool at Kastle Kaos. Fixes saves being nuked from existence on credits
  • Apaarently the Backup DK Barrels can no longer be used on the map? Fixes a related crash
  • Some logic updates

1.0.2

  • Bonus Coins in-game are now capped at 5
  • Demo playbacks are now disabled
  • An attempt was made to fix the miscolored "CLEAR" label in some scenarios
  • Rule macros can now be used with UT's /explain

1.0.1

  • Changed some client messages to actually tell they're from Toluca instead of DKC2
  • Reverted the change that disallowed cogs from being added into the pool
    • They need to exist as an alternate way to enter Krematoa levels without Bonus Coins (makes GitHub test happier)

1.0.0

  • New options to allow unlocking Progressive Vehicle items other than multiworld items
    • Via Banana Bird count
    • Via worlds unlocked
  • Swanky's Sideshow games can be valid locations (beat each 3 per world)
    • This also removes the bear coin cost to enter a game
  • KONG letters progress is saved per level upon collecting them
  • Bear Brothers' trade sequence can be shuffled
    • Adds 3 locations to the Banana Bird as locations option
    • Removes giving Barnacle a shell as a requirement for the rare flower to appear on the map
    • Rare flower no longer checks for Razor Ridge completion, only Barbos
    • Mirror item in Bazaar expects you to reach either Cove or Mekanos to consider it in logic (no one wants to farm coins)
  • Added a label to every world that informs what's the current progress on level clears and how many are required to fight the world's boss
  • Added an option to swap Kaos Kore and Knautilus levels
    • Goal option is updated to reflect that the goal is now either Kastle KAOS or Knautilus instead of KAOS Kore or Krematoa
  • Implemented more cog_placement options:
    • krematoa_level_clear: Places them at level ends in Krematoa
    • krematoa_anywhere: Places them anywhere in Krematoa. Includes Extra Cogs.
  • Added an option to have additional Banana Birds, Cogs and Bonus Coins in the item pool
  • Added the ability to change the Kongs' palettes
  • Generator no longer places Cogs if Knautilus isn't a valid goal
  • Allow setting to 0 the required level clears per world
  • Fixed an issue with levels on Krematoa trying to get alternate palettes after Knautilus surfaces
  • Level ID is now sent via Data Storage (for PopTracker auto tabbing)
  • A few logic changes

0.2.0

  • Implemented level shuffle
  • Enhanced the save/load procedure in both client and ROM
    • Fixes missing items that are received before opening a save
    • Fixes banana radar being unlocked from the start
  • Extra hit indicator is now shown on boss battles and bonuses
  • Extra hit now works with lightnings, Bleak and Toboggan
  • Backup DK Barrels now require pressing SELECT when converted or riding an animal
  • Added a new option that allows you to pre-set a new default save file name
  • Made it so excluded level clears have no logical weight to unlock world bosses
    • You can still clear those levels to access the boss out of logic
  • Kong-fused Cliffs no longer ignores not having Climb
  • Fixed Carry being given upon exiting a Bonus that had an invisible collectible nearby and the radar was active
  • Fixed some visual glitches related to locked items not properly despawning certain sprites
  • Added a missing banana bunch in Buzzer Barrage
  • Swapped Stampede Sprint bonuses
  • Added collect support
  • Updated a few area names
  • Several logic changes
